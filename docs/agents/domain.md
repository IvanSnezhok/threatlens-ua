# Domain docs

Проєкт має єдиний доменний контекст.

## Перед дослідженням

- Прочитати кореневий `CONTEXT.md`.
- Прочитати релевантні рішення в `docs/adr/`, якщо вони існують.
- Для деталей реалізації звертатися до `docs/ARCHITECTURE.md`, `docs/METHODOLOGY.md` і `docs/OPERATIONS.md`.

## Правила

- У коді, тестах та issue використовувати терміни з `CONTEXT.md`.
- Не змішувати офіційні тривоги, повідомлення джерел, події загроз, оцінки ризику та сповіщення користувачів.
- Якщо запропонована зміна суперечить ADR, явно зазначити конфлікт.
