# Issue tracker: GitHub

Issues і PRD цього репозиторію зберігаються в GitHub Issues. Для операцій використовується `gh` у клоні репозиторію.

## Авторство і текст

- Issue створюються через GitHub-акаунт власника репозиторію; перед публікацією потрібно перевірити активний акаунт через `gh auth status`.
- У назві, описі та коментарях заборонені згадки Codex, Claude, ШІ, агента, автоматичної генерації або співавторства інструментів.
- Текст має читатися як звичайний технічний опис від власника проєкту.
- Issue не створюється без прямого прохання користувача опублікувати його.

## Операції

- Створення: `gh issue create --title "..." --body-file <file>`.
- Перегляд: `gh issue view <number> --comments`.
- Список: `gh issue list --state open` із потрібними JSON-полями або фільтрами.
- Коментар: `gh issue comment <number> --body-file <file>`.
- Мітки: `gh issue edit <number> --add-label "..."`.
- Закриття: `gh issue close <number> --comment "..."`.

Репозиторій визначається з `git remote -v`.
